# HMU-Bench Prompt Templates

This directory publishes the answering and evaluator prompt templates used by
the HMU-Bench pipelines.

- `abc_answering.md`: Chinese and English ABC answering prompts.
- `abc_evaluator.md`: ABC 0–4 evaluator prompt and input schema.
- `audio_answering.md`: Chinese and English full-track audio answering prompts.
- `audio_evaluator.md`: Audio 0–4 evaluator prompt and input schema.
- `manifest.json`: prompt versions and generation settings.

The templates contain no question-specific reference answers, evidence, or
model responses.
